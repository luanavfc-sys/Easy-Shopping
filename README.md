
# 🛍️ Easy Shopping Via Mobile

Este é um projeto de uma landing page desenvolvido durante os estudos no DevClub, com o objetivo de praticar HTML5 e CSS3, criando um layout moderno e responsivo.

Além da versão para desktop, também desenvolvi a versão para dispositivos móveis, adaptando o layout para diferentes tamanhos de tela utilizando CSS responsivo.

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
- Responsividade (Media Queries)

## 📱 Funcionalidades

- Layout moderno e organizado.
- Versão para desktop.
- Versão totalmente responsiva para celulares.
- Estrutura semântica em HTML.
- Estilização utilizando CSS.

## 🎯 Objetivo

Praticar conceitos fundamentais de desenvolvimento Front-End, como:

- Estruturação de páginas com HTML.
- Estilização com CSS.
- Posicionamento de elementos.
- Responsividade.
- Organização do código.

## 📂 Como executar

1. Clone este repositório:
```bash
git clone https://github.com/seu-usuario/Easy-Shopping.git
```

2. Abra a pasta do projeto.

3. Execute o arquivo `index.html` no navegador.
